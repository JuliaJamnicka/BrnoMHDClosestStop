# Fčil

![Fčil](docs/brand/fcil-wordmark.svg)

Real-time departures from the closest Brno public transport stop, on the phone, in a home-screen widget
and on the watch: Huawei Watch GT (HarmonyOS lite wearable, `watch/`) and Garmin (Connect IQ, `garmin/`).
The phone app (`android/`) does the location and talks to the backend (`backend/`); the watches ask it.

See [docs/SPEC.md](docs/SPEC.md) for the technical specification.
